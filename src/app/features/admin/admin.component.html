🚀 ¿Cómo tener tu servidor cloud 100% gratuito en Render.com?
  1. Crea una cuenta gratuita en Render.com.
  2. Haz clic en New + → Web Service y conecta este repositorio de GitHub.
  3. Configura las opciones del servicio:
    • Root Directory: server
    • Build Command: npm install && npm run build
    • Start Command: npm start
  4. Copia la URL HTTPS generada (ej: https://tu-servicio.onrender.com/api) y pégala aquí.
